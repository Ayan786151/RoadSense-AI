# Data Dictionary — RoadSense AI

## Datasets

### `data/traffic_simulation.csv`
| Property | Value |
|:---------|:------|
| **Source** | Synthetic — generated by `sim.py` |
| **Type** | Panel data (zone × week) |
| **Size** | 2,600 rows (50 zones × 52 weeks) |
| **Scope** | Simulated urban traffic, incidents, and environmental conditions |
| **Limitations** | Incident target is generated from a known formula using the same features. Not real-world data. |

### `data/simulation_temporal_features.csv`
| Property | Value |
|:---------|:------|
| **Source** | Derived — generated by `analysis/temporal_features.py` from `traffic_simulation.csv` |
| **Type** | Engineered temporal features for ML training |
| **Size** | 2,600 rows with ~55 columns |
| **Features** | Lag-1, rolling 4-week, WoW changes, pct changes, OLS trend slopes |
| **Leakage status** | Clean — all temporal features use strict `shift(1)` and `min_periods=4` |

### `data/risk_predictions.csv`
| Property | Value |
|:---------|:------|
| **Source** | Model output — generated by `models/train_model.py` |
| **Type** | Test set predictions (Weeks 47–52) |
| **Contents** | Zone features + actual incidents + predicted risk probability |

### `data/final_priority_results.csv`
| Property | Value |
|:---------|:------|
| **Source** | Derived — generated by `priority/priority_engine.py` |
| **Type** | Priority-scored and ranked zones |
| **Contents** | Component scores + final priority + location mapping |

### `data/heatmap_data.csv`
| Property | Value |
|:---------|:------|
| **Source** | Derived — latest week extract from `final_priority_results.csv` |
| **Type** | Map-ready data with lat/lon coordinates |
| **Coordinates** | Real Indian city coordinates (Mumbai, Delhi, Lucknow, Chennai) |
| **Zone mapping** | Synthetic zone IDs mapped to real neighborhood names |

### `data/location_mapping.csv`
| Property | Value |
|:---------|:------|
| **Source** | Manually curated |
| **Type** | Zone ID → location name, city, lat/lon mapping |
| **Scope** | 50 zones across 4 Indian cities |
| **Coordinates** | Real geographic coordinates for actual neighborhoods |

### `data/calibration_config.json`
| Property | Value |
|:---------|:------|
| **Source** | Manually configured |
| **Type** | Camera calibration parameters (image points → world points) |
| **Status** | Demo calibration — not surveyor-certified |

### `data/temporal_traffic_store.csv`
| Property | Value |
|:---------|:------|
| **Source** | Accumulated from live vision pipeline sessions |
| **Type** | Historical camera observations for temporal feature computation |

### `data/vision_traffic_metrics.csv`, `data/movement_traffic_features.csv`, `data/vision_congestion_features.csv`
| Property | Value |
|:---------|:------|
| **Source** | Vision pipeline output |
| **Type** | Per-timestamp vehicle detection, tracking, speed, and congestion features |

## Models

### `models/best_risk_model.pkl`
| Property | Value |
|:---------|:------|
| **Type** | scikit-learn Pipeline (StandardScaler + OneHotEncoder + RandomForestClassifier) |
| **Training data** | Synthetic simulation |
| **See** | `models/MODEL_CARD.md` for full documentation |

### `yolo11n.pt`
| Property | Value |
|:---------|:------|
| **Type** | YOLOv11 Nano object detection weights |
| **Source** | Ultralytics pretrained on COCO |
| **Classes used** | car (2), motorcycle (3), bus (5), truck (7) |

## Column Glossary

| Column | Unit | Description |
|:-------|:-----|:------------|
| `zone_id` | ID | Unique zone identifier (Zone_01 to Zone_50) |
| `week` | integer | Week number (1–52) |
| `zone_type` | category | Urban archetype |
| `population_density` | persons/km² | Simulated residential population density |
| `road_capacity` | index (0–100) | Base road infrastructure capacity |
| `effective_road_capacity` | index (0–100) | Capacity adjusted for weather/events |
| `vehicle_density` | vehicles/km² | Simulated vehicle concentration |
| `traffic_pressure` | ratio | vehicle_density / effective_road_capacity |
| `congestion` | index (0–100) | Non-linear sigmoid response to pressure |
| `average_speed` | km/h | Mean traffic speed |
| `red_light_violations` | count | Poisson-distributed violation count |
| `incident_occurred` | binary | Whether an incident occurred (target) |
| `incident_count` | count | Number of incidents if occurred |
| `priority_score` | index (0–100) | Weighted composite: 40% risk + 25% population + 20% vehicle + 15% trend |
| `priority_level` | category | CRITICAL / HIGH / MODERATE / LOW |
